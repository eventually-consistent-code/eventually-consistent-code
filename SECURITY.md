# Security policy

Security maintainer: John Reed ([@eventually-consistent-code](https://github.com/eventually-consistent-code))

## Reporting a vulnerability

Report security issues privately through GitHub's vulnerability
reporting for this repository:

https://github.com/eventually-consistent-code/eventually-consistent-code/security/advisories/new

Please do not open a public issue for a vulnerability. Include the
commit or version you are running and a reproduction. You will get an
acknowledgement within seven days and a fix or a mitigation plan within
thirty.

## Supported versions

Security fixes land on the default branch (`main`). Older commits and
tags do not receive them.
